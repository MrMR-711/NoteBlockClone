# <a href="#!"><img src="docs/readme-svg/sun.svg" width="24" height="24" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 3px 0;pointer-events:none;"></a> NoteBlockClone Changelog

<details>
<summary> <a href="#!"><img src="docs/readme-svg/flask.svg" width="20" height="20" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"></a> Version 1.1.0</summary>

### <a href="#!"><img src="docs/readme-svg/sparkles.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"></a> Core Features
- Full vanilla Note Block behavior under the separate ID `clone:noteblock_clone`
- Rising-edge redstone response, signal conduction and piston immovability
- 18 instruments based on the block below, including the copper trumpet family
- Click tuning from 00 to 24 with vanilla sound and a colored particle
- Silence when blocked above, plus mob-head sounds
- Pitch storage via the `clone:octave` and `clone:semitone` block states
- Crafting: 1 vanilla note block + 1 redstone

### <a href="#!"><img src="docs/readme-svg/tools.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"></a> Fixes & Improvements
- Fixed pitch encoding (×13), ghost-block prediction, colorless particles and the bass instrument
- Rebuilt the instrument table against vanilla and added missing blocks
- Updated manifests, two-way pack dependency and resource-pack versioning

### <a href="#!"><img src="docs/readme-svg/book.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"></a> Docs & Packaging
- Bilingual README, MIT license and author metadata
- Renamed the pack folders to `NoteblockCloneBP` and `NoteblockCloneRP`

</details>
